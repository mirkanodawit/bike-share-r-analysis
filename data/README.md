# Dataset Setup

Place the following files in the repository root before running the notebook:

- `chicago.csv`
- `new-york-city.csv` or `new_york_city.csv`
- `washington.csv`

All three datasets contain these core fields:

- Start Time
- End Time
- Trip Duration
- Start Station
- End Station
- User Type

Chicago and New York City also contain Gender and Birth Year. The notebook uses only the shared fields for three-city comparisons.
